# Υπολογισμός Κυκλοφορητή — Web Tool

**🌐 Live:** https://vkocmac.github.io/PumpCalculator/ ·
**Repo:** https://github.com/vKocmac/PumpCalculator ·
**Deploy νέας έκδοσης:** `deploy.ps1` (τρέχει tests πρώτα, μετά push)

Απαιτούμενο **μανομετρικό (H)** και **παροχή** κυκλοφορητή για κύκλωμα νερού ή γλυκόλης.
Αντικαθιστά το `Υπολογισμός Κυκλοφορητών — Generic Template.xlsx`.
Εμφάνιση: ίδιο σύστημα με το LoadCalculator (φωτεινό θέμα, `design/DESIGN.md` εκεί).

## Χρήση
- Διπλό κλικ στο **`index.html`** (τρέχει τοπικά, offline, χωρίς εγκατάσταση).
- Αριθμημένες ενότητες με μπάρα προόδου: **Έργο → Ρευστό → Κλάδοι → Εξοπλισμός → Αντλία**.
  Οι κλάδοι παίρνουν ✓ μόνοι τους όταν δεν λείπει τίποτα (με «!» όταν έχουν παρατηρήσεις)·
  οι υπόλοιπες ενότητες όταν πατήσεις «Επόμενο».
- **Κλάδος** = κωδικός (L1…) + περιγραφή (π.χ. «Σιδηροσωλήνας λεβητοστασίου»). Η περιγραφή
  φαίνεται στη λίστα και στο PDF.
- **Δίκτυο:** κάθε κλάδος έχει «Μετά από» (τον κλάδο ανάντη). «+ Κλάδος μετά» συνεχίζει τη
  διαδρομή, «+ Παράλληλος» ανοίγει διακλάδωση. Κάθε διαδρομή από την αντλία ως το τέλος είναι
  ένα **κύκλωμα**· το H βγαίνει από το **δυσμενέστερο**. Για τα άλλα δίνεται η ΔP που περισσεύει
  και το Kv βάνας εξισορρόπησης.
- **Είδος κλάδου:** Προσαγωγή + επιστροφή (L μίας διαδρομής, ×2) · Μόνο προσαγωγή · Μόνο
  επιστροφή · Συνολικό μήκος (χωρίς ×2).
- **Q** δίνεται απευθείας ή από **φορτίο kW** με ΔT σχεδιασμού (ρ, cp του ρευστού).
- **Εξοπλισμός** με ΔP από φύλλο: ανά κλάδο (FCU, ενδοδαπέδια) ή κοινός για όλα (εναλλάκτης,
  λέβητας) — σε kPa ή m.
- **Ρευστό**: νερό ή PG/EG 0–60% κ.β. με ιδιότητες ανά θερμοκρασία και σημείο πήξης.
- **Παλαιό δίκτυο**: αυξημένη τραχύτητα σωλήνων (`kAged` στο `data.js`).
- **Ανοιχτό κύκλωμα**: στατικό ύψος προστίθεται μετά την προσαύξηση.
- **Αντλία** (προαιρετικό): 3–5 σημεία καμπύλης → σημείο λειτουργίας, υδραυλική ισχύς,
  ισχύς άξονα με η.
- **Έλεγχοι**: ταχύτητα με όριο ανά διάμετρο, απώλεια ανά μέτρο (Pa/m), στρωτή/μεταβατική ροή,
  ισοζύγιο παροχών σε διακλαδώσεις, authority βάνας ελέγχου, ελάχιστη ΔP βάνας εξισορρόπησης.
- **Αναφορά PDF** · 💾 **Αποθήκευση .json** / 📂 **Φόρτωση .json**. Auto-save στον browser.
  Παλιά αρχεία ανοίγουν κανονικά: οι κλάδοι γίνονται αλυσίδα σε σειρά με «Συνολικό μήκος»
  και το «L1 — κείμενο» χωρίζεται σε κωδικό και περιγραφή — ίδιο H με πριν.

## Εμπλουτισμός βάσης (χωρίς κώδικα)
Όλα τα δεδομένα στο **`data.js`** (`window.DB`):
- `PIPE_FAMILIES` — υλικά & διατομές `[ετικέτα, D_ext, τοίχωμα, D_int]`, τραχύτητα `k` / `kAged`.
- `FITTINGS` — εξαρτήματα με προεπιλεγμένο `zeta` ή/και `kv`· `role` για βάνες ελέγχου/εξισορρόπησης.
- `GLYCOL` — ν/ν_νερού, ρ, cp ανά θερμοκρασία (−30…90 °C) και συγκέντρωση (0…60% κ.β.), σημείο πήξης.
  Πηγή: Melinder, IIR 2010 (μέσω CoolProp). Η παρεμβολή δίνει ν έως +4% (συντηρητικά).
- `KINDS` — είδη κλάδων. `DEFAULTS` — όρια ταχύτητας ανά διάμετρο, Pa/m, authority κ.λπ.

Re=76011, λ=0.0189, ΔP_L1=2.126 mWS — ταυτίστηκαν σε Node + Python.
