# Υπολογισμός Κυκλοφορητών — Web Tool

**🌐 Live:** https://vkocmac.github.io/PumpCalculator/ ·
**Repo:** https://github.com/vKocmac/PumpCalculator ·
**Deploy νέας έκδοσης:** `deploy.ps1` (τρέχει tests πρώτα, μετά push)

Υπολογισμός απαιτούμενου **μανομετρικού (H)** δευτερεύοντος κυκλοφορητή με βάση
Darcy-Weisbach (σωλήνες) + μέθοδο ζ / Kv (εξαρτήματα). Αντικαθιστά το
`Υπολογισμός Κυκλοφορητών — Generic Template.xlsx`.

## Χρήση
- Διπλό κλικ στο **`index.html`** (τρέχει τοπικά, offline, χωρίς εγκατάσταση).
- Πρόσθεσε κλάδους **L1, L2, …** → όρισε Q, υλικό/διατομή/μήκος, εξαρτήματα.
- **Ρευστό**: Νερό ή Γλυκόλη (PG/EG) με %  → προσαρμόζει το ιξώδες ν.
- **Πρόσθετες απώλειες (καρφωτά)**: σταθερά ΔP (π.χ. εναλλάκτης, worst-loop UFH).
- **Προσαύξηση ασφαλείας %** στο τελικό H.
- 🖨 **Αναφορά** → νέο παράθυρο, σύνοψη + αναλυτικά ανά κλάδο + παράρτημα τύπων → εκτύπωση/PDF.
- 💾 **Αποθήκευση .json** (commit-able στο vault) / 📂 **Φόρτωση .json**. Auto-save στον browser.
- Πεδία που λείπουν → κόκκινο πλαίσιο + λίστα ελλείψεων· warnings ταχύτητας (0.5–1.5 m/s ιδανικό).

## Εμπλουτισμός βάσης (χωρίς κώδικα)
Όλα τα δεδομένα στο **`data.js`** (`window.DB`):
- `PIPE_FAMILIES` — υλικά & διατομές `[ετικέτα, D_ext, τοίχωμα, D_int]`, αδρότητα `k`.
- `FITTINGS` — εξαρτήματα ανά κατηγορία με προεπιλεγμένο `zeta` ή/και `kv`.
- `FLUIDS` — πίνακες ιξώδους/πυκνότητας (γλυκόλη = προσεγγιστικά, διορθώσιμα).
- `DEFAULTS` — θερμοκρασία, margin, όρια ταχύτητας.

## Αρχεία
`index.html` · `styles.css` · `app.js` (μηχανή+UI) · `data.js` (βάση). Καθαρό vanilla JS —
ανεβαίνει ως-έχει σε **GitHub Pages** για online χρήση.

## Επαλήθευση
Το engine επαληθεύτηκε vs τους τύπους του Excel (Ιδ.1): ν=0.597e-6, v=1.387 m/s,
Re=76011, λ=0.0189, ΔP_L1=2.126 mWS — ταυτίστηκαν σε Node + Python.

**Αυτόματα tests** (37 checks — πλήρες Ιδ.1, γλυκόλη, εναλλαγή ζ/Kv, validation,
συνέπεια D_int=D_ext−2t σε όλη τη βάση):
```
node tests/test_engine.js
```
Τρέξε τα ξανά μετά από κάθε αλλαγή σε `app.js` ή `data.js`.
